# RWP roadmap

## Shipped foundation

Public-data track map and linear weather, editable deterministic water-volume scenario, two gross gauge basins, gauge observations where available, local report entry and AI evidence export. Provider-generated AI remains configuration-dependent.

## Make the flood layer defensible

- Confirm current route/branch limits and exact railway asset inventory; add culvert capacity, invert levels, condition and historic blockage/ice incidents where rights permit.
- Delineate upstream catchments at each opening; identify genuine flow paths, storage and diversions. Add Alberta data for Hardisty coverage.
- Add catchment-average precipitation forecasts/observations, measured or independently sourced SWE, soil frost and antecedent wetness with provenance.
- Connect WSA/ECCC gauge feeds with explicit upstream/downstream relationships. No fixed travel time from simple gauge proximity.
- Add a routed hydrologic/hydraulic model only after inputs and calibration are adequate. Keep scenario, forecast and observed evidence distinct.

## Make social evidence useful

- Build a source inventory per catchment: public resident posts, municipalities, road authorities, local news and field reports.
- Use permitted APIs/licensed access. Public visibility does not guarantee reliable historical access or permission for bulk scraping; private groups are not an ingestion source without authorization.
- Extract event time, publication time, landmarks, firsthand/repost status and location confidence; deduplicate and preserve original links.
- Review basin membership and event-dependent connectivity. Nearby does not mean upstream; inside a basin does not prove routing to a crossing.
- Replay Birch and Tisdale plus quiet days using only evidence available at the time. Measure social contribution separately from weather/gauges.

## Add AI responsibly to the workflow

- Configure and exercise the provided server-side gateway; compare generated briefs against the underlying evidence.
- Add human-reviewed location extraction and report clustering without promoting uncertain claims to verified facts.
- Calibrate review thresholds and review effort using missed events, false positives and actual inspection outcomes.
- Add authentication, durable evidence storage, auditing and notifications only when users, access rules and operational responsibilities are defined.
